# Farzam.nl SEO Architecture

## Purpose

This document defines the SEO architecture for Farzam.nl.

SEO is not a blog topic. SEO is a structural system that must be applied across the entire website.

The goal is to build Farzam.nl as a premium Growth System platform that can rank for targeted strategic topics while converting visitors into newsletter subscribers, registered users, course participants, webinar attendees, and consulting leads.

---

## Core SEO Principle

Every page must be designed with:

- Clear search intent
- One primary keyword theme
- Supporting semantic topics
- Strong heading hierarchy
- Internal links
- Metadata direction
- Schema-ready structure
- Fast-loading Elementor layout
- Conversion intent

SEO must support brand authority, not cheap traffic.

---

## Website-Level SEO Goals

1. Build authority around Growth Systems
2. Rank for strategic growth, positioning, and business clarity topics
3. Attract founders, SMEs, experts, consultants, and startups
4. Convert organic visitors into subscribers, users, course leads, and consulting leads
5. Build topical clusters around Farzam’s core positioning
6. Support long-term organic growth for Farzam.nl

## Technical SEO Rules

The site should be built with:

- Clean URL slugs
- One H1 per page
- Clear H2 and H3 structure
- Optimized meta titles
- Optimized meta descriptions
- Compressed images
- WebP image format where possible
- Lazy-loaded visuals
- Lightweight motion
- Fast Elementor sections
- No unnecessary plugins
- Mobile-first responsive design
- Accessible contrast
- Descriptive alt text
- Breadcrumb support where useful
- XML sitemap via Yoast
- Canonical URLs
- Schema-ready templates

---

## Recommended Schema Types

Use schema where appropriate:

- Organization / Person schema for Home and About
- Article schema for Blog posts
- Course schema for Courses
- Event schema for Webinars
- FAQ schema for key pages
- Breadcrumb schema across the site
- WebPage schema for main pages
- ContactPage schema for Contact
