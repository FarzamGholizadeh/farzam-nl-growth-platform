# MVP Scope

## Purpose

This document defines the first version of Farzam.nl.

The goal of the MVP is to launch a focused, premium, and strategically clear website without making the platform too complex too early.

The MVP should prove the core positioning, support lead generation, and create the foundation for future courses, dashboard, automation, and membership features.

Farzam.nl must launch first as a clear Growth System platform.

Not a portfolio.

Not an agency website.

Not an AI tool website.

---

## Core MVP Principle

The MVP should focus on clarity before complexity.

The first version must help visitors understand:

1. Who Farzam is
2. What a Growth System is
3. Why scattered marketing is not enough
4. How Farzam thinks
5. What strategic modules are available
6. How to start a serious conversation
7. How to complete Growth Diagnosis
8. How to subscribe for future content

Do not add advanced features before the core message is clear.

---

## Core Positioning for MVP

The MVP must position Farzam as:

1. Growth Strategist
2. Growth System Designer
3. Business-Oriented Thinker

The MVP must not position Farzam as:

1. Traditional marketer
2. Freelance marketer
3. Social media manager
4. AI tool operator
5. Generic agency owner

Core message:

Build a Growth System, not just more marketing.

Marketing, content, AI, automation, websites, and campaigns are tools inside the Growth System.

They are not the identity of the brand.

---

## Public Copy Rule

All public website copy in the MVP must follow:

`content/COPYWRITING_RULES.md`

Main rules:

1. Do not use dashes.
2. Do not use AI-sounding language.
3. All text must feel human, natural, professional, and premium.
4. Avoid robotic sentence structures.
5. Avoid generic AI phrases.
6. Avoid over-polished artificial wording.
7. Write like a strategic human consultant.
8. Keep the tone clear, calm, executive, and trustworthy.

No page should be published before copy is reviewed against this rule.

## MVP Page Priority

Build pages in this order:

1. Home
2. Growth Systems
3. Modules
4. Contact
5. Blog structure
6. About
7. Work
8. Studio

Reason:

Home introduces the platform.

Growth Systems explains the core methodology.

Modules shows what Farzam can help with.

Contact creates the conversion path.

Blog structure prepares organic growth.

About, Work, and Studio build trust and credibility.

## MVP SEO Scope

Use reference:

`seo/SEO_ARCHITECTURE.md`

For MVP, configure:

1. SEO title for each public page
2. Meta description for each public page
3. One H1 per page
4. Clean URL slug
5. Internal links
6. Blog categories
7. Noindex for account pages if they exist

Do not over-optimize.

Do not keyword stuff.

SEO must feel natural and strategic.

---

## MVP Design Scope

Use references:

1. `design-system/DESIGN_SYSTEM.md`
2. `elementor/custom-css/FARZAM_GLOBAL_STYLE.md`

Design must feel:

1. Premium
2. Minimal
3. Executive
4. Spacious
5. Calm
6. Light
7. Strategic
8. Trustworthy

Avoid:

1. Generic stock images
2. Loud AI visuals
3. Heavy gradients
4. Agency template clutter
5. Cheap icons
6. Overanimated sections

---

## MVP Motion Scope

Use reference:

`elementor/custom-js/FARZAM_PREMIUM_MOTION.md`

Motion should be limited to:

1. Soft section reveals
2. Subtle card hover
3. Smooth hamburger menu
4. Button hover
5. Gentle form step transition if needed

Avoid:

1. Heavy parallax
2. Scroll hijacking
3. AI particles
4. Neon glow
5. Bouncy effects
6. Auto-moving sliders

---

## MVP Automation Scope

For MVP, automation can be simple.

Required:

1. Form submissions send email notification
2. Newsletter submissions are saved somewhere reliable
3. Growth Diagnosis submissions are stored or emailed clearly
4. Strategy call bookings are captured if booking tool is active

n8n can be Phase 2 if MVP speed is more important.

Prepare for future n8n by keeping form fields clean and structured.

---

## Out of Scope for MVP

Do not prioritize these in the first version unless the core site is already strong:

1. Full dashboard
2. Paid courses
3. Full LMS system
4. Complex membership levels
5. WooCommerce setup
6. Advanced n8n workflows
7. Skool integration
8. YouTube automation
9. Multi-step CRM segmentation
10. Complex personalization
11. Advanced analytics dashboard

These belong to Phase 2.

---

Before MVP launch, confirm:

1. Header is active
2. Footer is active
3. Home page is complete
4. Growth Systems page is complete
5. Modules page is complete
6. Contact page is complete
7. Blog structure exists
8. About page is complete
9. Work page is complete or has selected experience
10. Studio page is complete
11. Forms are tested
12. Newsletter form works
13. Strategy Call CTA works
14. Mobile layout is checked
15. SEO titles are added
16. Meta descriptions are added
17. Internal links work
18. Public copy follows `content/COPYWRITING_RULES.md`
19. No public website copy uses dashes
20. No public website copy sounds robotic or AI-generated

---

## MVP Success Criteria

The MVP is successful when:

1. Visitors immediately understand Farzam’s positioning
2. Growth Systems are clearly explained
3. The website does not feel like a generic agency site
4. The website does not feel like an AI tool website
5. The design feels premium and calm
6. The copy feels human and strategic
7. The Contact page creates a serious next step
8. The Growth Diagnosis path is clear
9. The blog structure supports future SEO growth
10. The site is ready to expand into courses, dashboard, and automation

---

## Final MVP Rule

The MVP should not try to do everything.

It should do the right things clearly.

The first version must make the positioning believable, the system understandable, and the next step easy.

Farzam.nl should launch as a focused Growth System platform with room to grow.
