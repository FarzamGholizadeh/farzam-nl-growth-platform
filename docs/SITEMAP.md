# Farzam.nl Sitemap

## Website Positioning

Farzam.nl is a premium multi-page Growth System consultancy platform.

The website must position Farzam as a Growth Strategist, Growth System Designer, and Business-Oriented Thinker.

It must not position him as:
- A traditional marketer
- A freelance marketer
- A social media manager
- An AI tool operator

Core message:

Build a Growth System, not just more marketing.

## Primary Website Goals

1. Build premium personal brand authority
2. Explain the Growth System methodology
3. Convert visitors into consulting leads
4. Build a blog-driven organic growth engine
5. Capture leads from YouTube, Skool, LinkedIn, X, Instagram, TikTok, and Google
6. Support course, webinar, and newsletter registration
7. Prepare the platform for n8n automation
8. Apply SEO structure across all pages

## SEO Structure

SEO must be applied across the whole website, not only the blog.

Every page must include:
- One clear H1
- Logical H2 and H3 hierarchy
- Page-level keyword intent
- Internal links
- Metadata direction
- Fast-loading Elementor layout
- Schema-ready structure
- Clear conversion intent

## Motion Direction

Motion must be premium and subtle.

Allowed:
- Calm section reveals
- Soft hover states
- Smooth page transitions
- Minimal parallax
- Animated framework diagrams
- Luxury micro-interactions

Avoid:
- Flashy animations
- Template-like movement
- Heavy scripts
- Noisy AI-looking effects

- Contact form
