# Farzam.nl Design System

## Purpose

This document defines the visual, UX, motion, and component direction for Farzam.nl.

Farzam.nl must feel like a premium Growth System consultancy platform, not a generic marketing website, freelancer portfolio, AI tool website, or social media service page.

The visual identity must communicate:

- Strategy
- Clarity
- Structure
- Trust
- Premium execution
- Calm intelligence
- Business maturity
- Human authority

---

## Core Design Direction

The design should feel like:

Apple + McKinsey + Premium SaaS + Independent Strategy Consultant

It should be:

- Minimal
- Clean
- Spacious
- Executive
- Light
- Structured
- Precise
- Calm
- Modern
- Trustworthy

It should not feel:

- Flashy
- Overanimated
- Template-like
- Cheap
- Too colorful
- Too dark
- Too AI-generated
- Like a typical freelancer site
- Like a social media marketing agency site

---

## Brand Identity

### Logo

Use the provided Farzam / FGS logo as the main brand mark.

Logo direction:
- Dark blue premium mark
- Clean and modern
- Should appear in header, footer, favicon direction, account dashboard, and course platform areas
- Do not redesign the logo
- Do not overdecorate the logo
- Give the logo enough whitespace

### Brand Feeling

The logo should anchor a visual system that feels:

- Executive
- Intelligent
- Calm
- Technical but human
- Premium but not cold

---

## Color System

The color palette should be inspired by the dark blue logo.

### Primary Colors

Primary Navy:
- Used for logo, key text, premium accents, buttons, and section anchors
- Direction: deep navy / blue-black

Suggested hex:
- `#0B1F3A`
- `#102A46`
- `#163B5C`

### Secondary Blue

Used for links, subtle highlights, active states, icons, and diagram lines.

Suggested hex:
- `#245C8F`
- `#2F6FA8`

### Light Background

Main background should stay light and clean.

Suggested hex:
- `#FFFFFF`
- `#F7F9FC`
- `#F3F6FA`

### Warm Neutral

Used to soften the interface and avoid looking too cold.

Suggested hex:
- `#F5F1EA`
- `#EEE8DE`

### Text Colors

Primary text:
- `#111827`

Secondary text:
- `#4B5563`

Muted text:
- `#6B7280`

Border:
- `#E5E7EB`

### Accent Color

Use accent color sparingly.

Possible accent:
- muted gold / sand for premium notes
- `#B8945E`
- `#C7A46B`

Do not overuse bright colors.

---

## Typography Direction

Typography must feel premium, editorial, strategic, and easy to read.

### Font Direction

Use modern sans-serif typography with strong hierarchy.

Recommended style:
- Large confident headlines
- Clean body text
- Slightly editorial spacing
- Strong contrast between headings and body
- No decorative fonts

Possible font direction:
- Inter
- Neue Haas Grotesk style
- Satoshi style
- Manrope
- Helvetica Now style

If custom fonts are not available, use:
- Inter or system sans-serif

### Heading Style

H1:
- Large
- Confident
- Minimal
- Strong line height
- Not too long
- Should feel like a strategic statement

Example:
Build a Growth System, not just more marketing.

H2:
- Clear section statements
- Strategic, not generic

H3:
- Used for modules, cards, proof points, and smaller frameworks

### Body Text

Body text should be:
- Human
- Clear
- Executive
- Not robotic
- Not hype-driven
- Easy to scan

Avoid:
- AI clichés
- Generic marketing language
- Empty buzzwords
- Overpromising

---

## Layout System

### General Layout

Use a premium grid-based layout.

Rules:
- Maximum content width should feel controlled
- Use generous whitespace
- Avoid crowded sections
- Avoid too many columns on mobile
- Keep visual rhythm consistent
- Each section should have one clear purpose

### Section Spacing

Desktop:
- Large sections should use generous vertical spacing
- Hero should breathe
- Content blocks should not touch edges

Mobile:
- Prioritize readability
- Keep CTA buttons accessible
- Avoid heavy animations
- Stack cards cleanly

### Grid Direction

Use:
- 12-column desktop grid
- 2-column / 3-column cards where appropriate
- Single-column mobile layout
- Clear alignment between headings, text, and visuals

---

## Header System

The header must be minimal.

Visible top bar elements:

1. Logo
2. Hamburger Menu
3. Register / Sign In
4. Book a Strategy Call

### Header Behavior

Desktop:
- Logo on the left
- Minimal actions on the right
- Hamburger opens full navigation

Mobile:
- Logo
- Hamburger
- Register / Sign In icon or text
- Book button may become compact

### Hamburger Menu

The hamburger menu should feel premium and editorial.

Menu items:
- Home
- Growth Systems
- Modules
- Work
- Blog
- Courses
- Studio
- About
- Contact

Hamburger menu behavior:
- Smooth open / close
- Full-screen or large side panel
- Clean typography
- Subtle divider lines
- No clutter
- Include short positioning line

Suggested menu footer:
Build a Growth System, not just more marketing.

---

## Button System

### Primary Button

Use for main conversion actions.

Examples:
- Book a Strategy Call
- Diagnose Your Growth System
- Create Your Account

Style:
- Deep navy background
- White text
- Rounded but not playful
- Strong hover state
- Subtle elevation or border transition

### Secondary Button

Use for exploration CTAs.

Examples:
- Explore Growth Systems
- View Modules
- Read the Blog

Style:
- White or transparent background
- Navy border
- Navy text
- Clean hover fill

### Tertiary Links

Use for inline navigation.

Examples:
- Read more
- View case study
- Explore course

Style:
- Text link
- Subtle underline or arrow
- No loud effects

---

## Card System

Cards should be used for:

- Modules
- Case studies
- Blog articles
- Courses
- Webinars
- Resources
- Dashboard items

Card style:
- Light background
- Thin border
- Soft radius
- Strong spacing
- Minimal shadow
- Clear hierarchy
- Calm hover state

- Heavy shadows
- Bright gradients

## Visual System

### Images

Use images and visuals that feel:
- Real
- Premium
- Strategic
- Human
- Clean
- International

Avoid:
- Generic AI stock imagery
- Overly futuristic robots
- Fake holograms
- Random 3D shapes
- Overused startup illustrations

### Diagrams

The website should use strategic diagrams to explain systems.

Diagram style:
- Minimal
- Line-based
- Soft blue/navy accents
- Clear labels
- Inspired by consulting frameworks
- Easy to understand

Use diagrams for:
- Growth System framework
- Customer journey
- AI workflow
- Content repurposing engine
- n8n automation map
- Course-to-consulting path

---

## Motion System

Motion should be premium, subtle, and performance-conscious.

### Allowed Motion

- Calm section reveal
- Soft fade-in
- Subtle slide-up
- Smooth hover states
- Gentle card elevation
- Subtle line drawing for frameworks
- Minimal parallax for hero only if lightweight
- Smooth hamburger menu open / close
- Dashboard micro-interactions

### Avoid Motion

- Flashy animations
- Fast bouncing
- Heavy 3D effects
- Overuse of parallax
- Cursor gimmicks
- Noisy scroll effects
- AI-looking motion
- Motion that slows the site

### Motion Principle

Motion should support clarity and premium feel.

It should not try to impress the user.

---

## Elementor Component Rules

All sections must be Elementor Pro friendly.

Design should be built with reusable sections and components.

Recommended reusable components:

- Hero section
- Section header block
- CTA block
- Module card
- Case study card
- Blog card
- Course card
- Webinar card
- Testimonial / proof card
- Framework diagram block
- Newsletter signup block
- Growth diagnosis form block
- User dashboard card
- Pricing / offer block if needed
- Footer block
- Hamburger menu overlay

### Elementor Rules

- Avoid overly complex nested containers
- Use global colors
- Use global fonts
- Use reusable templates
- Use custom CSS only where needed
- Keep animations lightweight
- Maintain responsive spacing
- Use semantic heading structure
