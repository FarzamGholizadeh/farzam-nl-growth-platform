# Modules Page Blueprint

## Page

Modules `/modules`

## Page Objective

The Modules page must present Farzam’s work as strategic modules inside a Growth System.

This page must not feel like a generic services page. The goal is to show that each module solves a specific part of a larger growth structure.

The page should help visitors understand which part of their growth system may need attention first, then guide them toward Growth Diagnosis or a Strategy Call.

---

## Target User Intent

Visitors on this page want to know:

- What Farzam can help with
- How the work is structured
- Which module fits their current situation
- Whether Farzam offers strategy, execution, or both
- How to start

## Section 4: How to Choose the Right Module

### Section Goal

Help users decide without feeling overwhelmed.

### Suggested H2

Start with the part of the system that is creating the most friction.

### Decision Guide

Use a simple diagnostic block:

- If people do not understand your value → Brand Positioning System
- If leads do not convert → Customer Journey System
- If content feels random → Content and Communication System
- If AI feels useful but messy → AI Workflow System
- If campaigns do not perform → Campaign and Funnel System
- If your website is unclear → Website and UX Direction
- If your personal brand lacks structure → Personal Brand Growth System
- If you are not sure → Growth Audit
