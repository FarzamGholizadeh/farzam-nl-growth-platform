# Courses Page Blueprint

## Page

Courses `/courses`

## Page Objective

The Courses page must become Farzam.nl’s education and lead-generation hub.

This page should serve visitors coming from YouTube, Skool, Blog, social platforms, newsletter, and Google. It should allow visitors to discover free resources, courses, workshops, webinars, and future paid learning products.

The page should support both education and conversion:

Visitor → Course / Webinar interest → Register → Learn → Newsletter nurture → Member-only Strategy Offer → Strategy Call

---

## Target User Intent

Visitors on this page may want to:

- Learn Farzam’s Growth System frameworks
- Access free resources
- Join a course
- Register for a webinar
- Enter from YouTube or Skool
- Create an account
- Understand whether Farzam’s thinking is useful
- Later book a consulting call
