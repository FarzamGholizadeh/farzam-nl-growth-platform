# AGENTS.md

## Purpose

This file gives clear instructions to any AI agent, Codex agent, developer, or automation system working on the Farzam.nl Growth Platform repository.

The goal is to prevent the project from being misunderstood or built in the wrong direction.

Farzam.nl must be developed as a premium Growth System platform, not as a generic portfolio, agency website, or AI tool website.

---

## Core Positioning

Farzam.nl positions Farzam Gholizadeh as:

1. Growth Strategist
2. Growth System Designer
3. Business-Oriented Thinker

The project must not position Farzam as:

1. Traditional marketer
2. Freelance marketer
3. Social media manager
4. AI tool operator
5. Generic agency owner
6. Template-based personal brand

Core message:

Build a Growth System, not just more marketing.

---

A Growth System combines:

## Website Copywriting Rules

All public website copy must follow these rules:

1. Do not use dashes.
2. Do not use AI-sounding language.
3. All text must feel human, natural, professional, and premium.
4. Avoid robotic sentence structures.
5. Avoid generic AI phrases.
6. Avoid over-polished artificial wording.
7. Write like a strategic human consultant, not like an AI assistant.
8. Keep the tone clear, calm, executive, and trustworthy.
9. Every sentence should feel useful, intentional, and natural.
10. If a sentence sounds like it was generated by AI, rewrite it.

This rule applies to:

1. Page copy
2. Headlines
3. Subheadlines
4. CTAs
5. Blog content
6. Course descriptions
7. Form text
8. Dashboard messages
9. Email copy
10. Newsletter text
11. Microcopy
12. SEO descriptions
13. Button labels
14. Error messages
15. Confirmation messages

Important clarification:

The no-dash rule applies to public website copy and user-facing writing.

Markdown documentation files may use normal Markdown syntax when needed for structure, lists, file paths, and technical documentation.

If any public text feels robotic, generic, overhyped, or AI-generated, rewrite it before publishing.

The final standard is simple:

The text should sound like Farzam speaking clearly, professionally, and strategically to a serious business audience.
